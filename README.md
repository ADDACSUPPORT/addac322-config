# ADDAC322 firmware

**Open the installer: https://addacsupport.github.io/addac322-config/**

Install the latest firmware on the ADDAC322's joystick (transmitter) and module
(receiver) straight from the browser, over USB, with no tools to install.

- Use **Chrome** or **Edge** on a computer. Other browsers can't talk to USB
  serial devices.
- Update **both** units to the same release. They share a wireless protocol,
  and a joystick and module from different releases may not work together.
- Your settings are kept: pair ID, ranges, offsets, morph and gate setup. If
  the installer offers to erase the device, leave it unticked.

---

This repository is published automatically from ADDAC's firmware repository on
every release, so changes made here are overwritten.
