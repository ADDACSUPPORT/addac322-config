ADDAC322 firmware

Release v0.2

Update both the joystick and the module to the same release. They talk over a shared protocol, and a joystick and module from different releases may not work together.

Joystick (transmitter)

The handheld controller. It has two USB-C ports: use the top one. The bottom one only charges the battery.

  1. Plug a USB-C data cable into the joystick's top port.
  2. Press Install and pick the port that appears.
This browser can't flash devices. Use Chrome or Edge on a computer. Flashing needs a secure (https) page.

ADDAC322 module (receiver)

The Eurorack module.

  1. Connect its native USB port to the computer.
  2. Press Install and pick the port that appears.
This browser can't flash devices. Use Chrome or Edge on a computer. Flashing needs a secure (https) page.

Keep your settings

If the installer offers to erase the device, leave it unticked. The update doesn't touch the pairing, ranges or gate setup, but an erase wipes them.

If the device isn't found

  • Try another cable: many USB-C cables only carry power.
  • Joystick: check the cable is in the top port; the bottom one only charges and never shows up as a device. If it still isn't found, hold the reset button on its side for about 2 seconds, until the green light comes on, then press Install again.
  • Module: hold BOOT, press and release RESET, then release BOOT, and press Install again. Power-cycle the module once it has finished.
